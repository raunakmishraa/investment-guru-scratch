# Investment Guru — HTML/CSS/JS Redesign

A framework-free redesign inspired by modern fintech/investment UX patterns, including the visual rhythm and content architecture seen in Bullhouse Investment.

## Stack
- HTML5
- CSS3
- JavaScript + jQuery
- GSAP + ScrollTrigger (CDN)
- Lenis smooth scrolling (CDN)
- AOS scroll reveals (CDN)
- Google Fonts (CDN)

## Pages
- index.html
- about.html
- trainings.html
- enrollment.html
- consultation.html
- contact.html

## Run
Open index.html directly, or use a local static server:
python -m http.server 8000

Then visit:
http://localhost:8000/

## Important
The site uses the current Investment Guru logo hosted at investmentguru.com.np. For production, download the logo into images/logo.jpg and replace the external logo URLs.

The forms are intentionally static-hosting friendly: they open the visitor's email client with a pre-filled message. Replace this with your preferred backend/API/form service when deploying.

No investment performance claims beyond the existing site's supplied figures were invented; the existing 5+ years, 500+ clients and 25% portfolio-growth figures are retained from the current website.
